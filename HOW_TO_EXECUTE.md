# 🛠️ How to Setup and Execute the Bio-Tracking Pipeline

This guide provides step-by-step instructions to clone, install, run, and deploy the **Automated Vesicle Tracking & Bio-Image Analytics Pipeline**.

---

## 📋 Prerequisites

Make sure you have the following software installed on your computer:

* **Git**: [git-scm.com](https://git-scm.com/)
* **Python 3.10+**: [python.org](https://www.python.org/)
* **Docker** *(Optional, only if running inside containers)*: [docker.com](https://www.docker.com/)

---
